\section{What the exploration showed}

\begin{itemize}
  \item \textbf{Everything breaks in the same place: near complete spatial randomness (CSR).} Across every feature set in \texttt{results/} (classical and topological):
  \begin{itemize}
    \item Below $\dt\approx0.6$ the 5-way classifiers recognise Thomas only $2$--$8\%$ of the time and call $59$--$86\%$ of those patterns Poisson (nested and LGCP alike: $51$--$82\%$ called Poisson)
    \item Parameter errors are largest near CSR and shrink as the structure strengthens: log-RMSE (mean over parameters) Thomas $\approx0.9 \to 0.4$, LGCP $\approx0.6 \to 0.25$ from $\dt<0.5$ to $\dt\ge8$ (best feature sets)
  \end{itemize}
\end{itemize}

\section{Design}

\begin{center}
\begin{tabular}{@{}llll@{}}
\toprule
stage & question & model & trained on \\
\midrule
1. filter      & Poisson, clustered or repulsive?      & trees & all simulated patterns \\
2. classifiers & clustered: Thomas / nested / LGCP / \emph{reject} & trees & in-regime patterns of the branch \\
               & repulsive: Mat\'ern II / \emph{reject}           &       & + reject examples \\
3. estimators  & the family's parameters (log-MSE)     & per family & that family's in-regime patterns \\
\midrule
Poisson        & intensity                             & $\hat{\nb}=n$ (exact MLE) & --- \\
\bottomrule
\end{tabular}
\end{center}

\begin{itemize}
  \item \textbf{Why filter:} near-CSR patterns carry no usable structure, so the filter calls them Poisson and fits $\hat{\nb}=n$. That is wrong as a label but fine as a fit, and every downstream model is trained only on patterns where its structure is visible
  \item \textbf{Reject:} patterns the filter lets through by mistake (mostly Poisson) are re-routed to Poisson by stage 2. Reject examples are Poisson patterns, the branch's own out-of-regime patterns, and the other branch's patterns
  \item \textbf{Each component is trained on its own}, from simulated patterns only; no component sees another's predictions. They are assembled only at test time
  \item \textbf{The assembled pipeline is scored end to end} by a proper scoring rule on simulations from the fitted model (Section~\ref{sec:scoring}). This rewards a useful fit rather than a correct label, and does not reuse the summary functions the models were trained on
\end{itemize}

\section{Regime analysis: where to cut}

\begin{itemize}
  \item \textbf{Question:} which function of a pattern's true parameters best predicts whether the filter sends it to its own group?
  \item \textbf{Candidates, per family:} raw parameters; physical ones (cluster overlap $\omega=\sigma\sqrt\kappa$, hard-core size, correlation range); a rough pair-count signal-to-noise ratio $\zeta$; and $\dt$
  \item \textbf{Score:} out-of-fold log-loss of a monotone fit, as a fraction of what a model given \emph{all} parameters achieves ($1$ = the coordinate explains everything the parameters can). Fitted on the filter's held-out predictions on the \emph{training} set, so the test set never picks the cutoff
\end{itemize}

\begin{itemize}
  \item \textbf{Physical coordinates match or beat $\dt$.} $\dt$ is built from the $L$-function, which the filter also sees, so a physical coordinate that ties it is the cleaner choice
  \item \textbf{Two-dimensional:} more points make the same overlap easier to see, so each cutoff is on (coordinate, $\nb$), written as one number coordinate$\,\times\,\nb^{a}$ with $a$ fitted
\end{itemize}

\subsection*{From curve to training data}
\begin{itemize}
  \item A pattern is \textbf{in regime} at threshold $\tau$ if the filter sends patterns like it to their own group with probability $\ge\tau$
  \item $\tau\in\{0, 0.3, 0.5, 0.7, 0.9\}$; $\tau=0$ is no filtering, the baseline the filter must beat
  \item Higher $\tau$ = cleaner but fewer training patterns (at $\tau=0.5$: Thomas keeps $49\%$, nested $83\%$, Mat\'ern II $88\%$, LGCP $66\%$)
\end{itemize}

\section{Scoring the whole pipeline}\label{sec:scoring}

\begin{itemize}
  \item \textbf{Per test pattern $x$}, simulate three models and score each against $x$ (lower is better):
  \begin{itemize}
    \item \textbf{fit}: the pipeline's $(\widehat{\text{family}}, \hat\theta)$
    \item \textbf{truth}: the true family at the true $\theta$ --- the floor
    \item \textbf{CSR}: Poisson with $\nb=n$ --- no structure
  \end{itemize}
  \item \textbf{Primary score: kernel score on local configurations.} Around each point, take its neighbours within $1.5$ mean spacings; compare the distribution of these local configurations in $x$ with that in the model's simulations, through a kernel. Strictly proper: the true model minimises it in expectation
  \item \textbf{Secondary score: Dawid--Sebastiani} on 14 geometric statistics (Voronoi cells, nearest neighbours, Delaunay edges), no persistent homology
  \item \textbf{Why not the obvious Wasserstein distance?} Two draws of the same clustered process do not line up point by point, so $W(x,\text{simulation})$ is large even for the true model. Tested: it could not tell the truth from CSR
  \item \textbf{Summaries}, pooled over $\sim$300 test patterns stratified by $\dt$ (never read single patterns):
  \[
    \text{regret} = S(\text{fit}) - S(\text{truth}), \quad
    \text{gain} = S(\text{CSR}) - S(\text{truth}), \quad
    \text{skill} = 1 - \frac{\sum \text{regret}}{\sum \text{gain}}
  \]
  skill $=1$: as good as the truth; $0$: no better than CSR
  \item \textbf{Power check (truth vs CSR):} at $\dt>4$ the kernel score prefers the truth on $93$--$100\%$ of patterns. Most of that power comes from higher-order structure, not the pair correlation the models were trained on
  \item \textbf{``Might as well be Poisson'' becomes testable:} on structured patterns the pipeline sends to Poisson, the fit \emph{is} CSR, so the claim is simply gain $\approx0$
\end{itemize}

\begin{itemize}
  \item $\tau$ is a dial between catching Poisson impostors and losing weak real patterns (accuracy counts a rejected real pattern as wrong)
  \item Training past the cutoff fixes Thomas: recall $0.33\to0.54$ --- trained on all Thomas patterns it learns ``Thomas is weakly clustered'', but the filter only passes clearly clustered ones
  \item Main remaining confusion is Thomas vs nested, and it is identifiability: a nested process whose outer level is smeared out \emph{is} a Thomas process (nested called nested: $96\%$ when the outer level is crisp, $37$--$46\%$ when smeared)
\end{itemize}

{\small For scale: on strongly structured patterns ($\dt>4$) the gain is $0.011\pm0.0015$, so the score has power where there is structure.}

\begin{itemize}
  \item \textbf{``Might as well be Poisson'' holds:} on every structured pattern the pipeline sends to Poisson, the true model scores no better than Poisson
  \item \textbf{Where it fits a family, the fit is as good as the truth} as far as either score can tell (skill $\approx1$)
  \item \textbf{$\tau$ does not matter end to end:} rejected patterns are near-CSR, so Poisson or a weak family fit are equally good
  \item \textbf{The estimator choice does not matter end to end either:} networks at stage 3 score the same as trees, as the per-stage results predicted
  \item Nested is the only family where the fit is slightly worse than the truth in both pipelines --- the Thomas/nested identifiability again
  \item \textbf{Caveat:} the fit is scored on the pattern it was estimated from, which flatters it (hence skill slightly $>1$). Next: fit on one replicate, score on the independent second replicate of the same $\theta$
\end{itemize}
